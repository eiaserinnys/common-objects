# Contributor instructions
Read docs/asset-spec.md before creating an asset. Keep asset sources separate from renderer and preview UI. The catalog supports metric-svg and procedural-svg assets; never claim metre dimensions for illustrative drawing coordinates. Metric geometry uses metres, Y-up, XZ ground, contact-center origin and scale [1,1,1]. Procedural SVG imports retain their declared coordinates and provenance. Preserve immutable source versions when geometry or semantics change. Do not commit credentials, private conversations, generated dist files, or dependencies. Run npm run validate, npm test and npm run build before a commit. For visual changes inspect desktop and narrow-screen Chromium previews, switching, rotation, zoom and duplicate state independence where supported. Never claim checks that were not run. Do not force push or deploy without explicit authorization.
