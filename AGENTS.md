# Contributor instructions
Read docs/asset-spec.md before creating an asset. Keep asset sources separate from renderer and preview UI. Every placeable asset, including newly produced daily props, uses 1 unit = 1 metre, Y-up, XZ ground, contact-center origin and default scale [1,1,1]. The catalog supports metric-svg and procedural-svg. Imported SVG assets preserve original source coordinates separately and require a documented physical calibration plus axis transform; viewport or thumbnail fitting is never a physical calibration. Record estimated dimensions and their reference honestly. Preserve immutable source versions when geometry or semantics change. Do not commit credentials, private conversations, generated dist files, or dependencies. Run npm run validate, npm test and npm run build before a commit. For visual changes inspect desktop and narrow-screen Chromium previews, switching, rotation, zoom and duplicate state independence where supported. Never claim checks that were not run. Do not force push or deploy without explicit authorization.
