## Interaction acceptance correction

The original acceptance at `5876e2a038ed300e30e724df7470ad5fd181aa90` treated eight static depictions as sufficient. This did not adequately cover ordinary mechanisms in four of those items. Fetched main again at that commit with a clean tree; this revision adds operating behavior and reevaluates acceptance by role.

- Drying rack v2: telescoping upper tier moves 0.58 m down/up; ground frame stays fixed.
- Ironing board v2: scissor legs and worktop move between 0.90 and 0.75 m working heights; available support metadata changes with the setting.
- Linen cart v2: caster pedals/shoes engage parking brakes. The preview blocks position and rotation edits while braked; release permits transport placement again.
- Dehumidifier v2: explicit discrete illustrative model. A cycle reduces simulated humidity five percentage points and collects 200 mL; a 600 mL full tank stops cycles until drained. It also stops at 45% humidity. Drain changes tank state without resetting humidity. Numeric state, water indication and cutoff are per instance and saved.

Four assets remain deliberately static: the fixed laundry table supports sorting/folding without an authored moving frame; the bench provides seating with no adjustment mechanism; the fixed long-tool stand provides parking hooks and a tray; the rigid two-step platform provides access without folding joints. They are accepted as fixed furniture, not as operating machines. Generic positioning and independent duplication remain available. Hook/cloth/person attachment is not implemented.

The changed four sources are v2, with their original v1 JSON preserved unchanged under `versions/1.json`. Old v1 saved arrangements using these sources are rejected explicitly by the current loader rather than silently reinterpreted; automatic migration is not implemented. The current mixed assembly references v2 and its new states.

## Limits

All dimensions are estimated. Discrete mechanisms do not provide continuous articulation or collision simulation. The washer still provides loading access, not an actual wash cycle. Dehumidifier values are a deterministic illustrative model, not a room sensor, thermodynamic calculation or timed process. Rack has no cloth/hook attachment or drying simulation. Cart brakes restrict preview editing, not physical motion in a world solver. Board contents must be repositioned manually. No ergonomic/load safety certification, architectural enclosure, GLB exporter, real-time shadows or swept-volume solver. Next priorities remain living-room soft seating/floor lighting, architecture and stronger attachment/appliance behavior.
