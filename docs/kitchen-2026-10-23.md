## Verification

- `npm run validate`, `npm test` (24 tests), `npm run build`.
- `node scripts/kitchen-check.mjs`: exact mesh bounds, both active state bounds and world support polygons in `kitchen-validation-result.json`.
- `python3 scripts/kitchen-browser-check.py`: built preview in system Chromium, desktop 1280×900 and narrow 390×844. Ten objects × four sides plus alternate states captured and visually inspected. Camera zoom/orbit, object rotation, XYZ placement, independent copies and 20-instance mixed-scene persistence across reload checked. Report: `kitchen-browser-result.json`.
- Salt cellar placed on bread-box lid at Y=0.192 m with unit scale; contact and fit checked numerically and visually in a shared scene.
- `npm run browser-check`: existing room artwork identity, room controls, narrow view, lamp SVG interaction/independent copies/persistence and navigation regression. Optional browser-requested `/favicon.ico` 404 is recorded separately from application failures in `browser-result.json`.
- Found and fixed average-depth occlusion artifacts: the shared SVG renderer now splits spanning polygons and contours with BSP ordering, and clips polygons at the near plane. Added crossing-face/edge and clipping regression tests. No WebGL revival.

Representative evidence: `screenshots/kitchen-2026-10-23/set-desktop.png`, `set-mobile.png`, `support-placement.png`, `inspection-contact-sheet.jpg`. Individual `object-N-{0,90,180,270,alternate}.png` files retain the full inspection captures; N follows the table order.

## Limits and environment

Playwright's bundled Chromium was absent; its CDN download returned 403 Domain forbidden. Installed `/usr/bin/chromium` provided the working fallback; no additional permission or paid service was required. The reusable browser checks accept CHROMIUM_PATH or a system Chromium fallback.

Not verified: real devices, other browser engines, manufacturer dimensions, load limits, physical collision/settling, weight/fluids/cutting/grinding, articulated motion or large-scene performance. Removed pieces leave the scene; the scale displays a static zero when powered. SVG has no shadows or lighting simulation. Ground grid is an above-ground placement guide. No deployment was performed.
