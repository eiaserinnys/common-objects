## Limits

These are 3D-coordinate drawings projected into SVG with the shared BSP painter renderer, not delivered GLB meshes. The timer uses an opaque stylized hourglass body, not refractive glass or flowing sand. Pip and letter inserts, covers, pegs and contents use discrete removal; no game rules, rolling, articulated mechanics, physics, load capacities, shadows or collision prevention. Letter tiles have illustrative glyphs rather than a playable alphabet. The shoe is a simplified horizontal household holder. Only the listed board patch is certified as a support; other tops are not. Tests use headless Chromium and narrow viewport emulation, not physical touch hardware. No website deployment.
