## Limits and next work

This is SVG projection with BSP painter ordering, not a delivered GLB mesh or physics engine. No lighting, shadows, refrigeration, coffee extraction, plumbing, drainage, steam or thermal simulation. Door/lever/flow states are discrete illustrations, not continuous motion. Static objects have disabled operation controls, not pretend mechanisms. Counter/shelf support metadata is a placement hint; moving furniture does not automatically carry placed objects. Display is open, with no transparent glass. Menu marks are decorative, not readable pricing. No furniture load/ergonomic certification, real-device performance testing or non-Chromium testing is claimed.

The arrangement demonstrates a common-scale service area and seating; it has no walls or customer/staff partition and is not a fully planned or accessibility-certified café. No new architectural room is counted. Next production should reuse this sink for a utility zone with washer and tall storage, followed by soft seating/living furniture. No separate website deployment or repository CI run is claimed.
